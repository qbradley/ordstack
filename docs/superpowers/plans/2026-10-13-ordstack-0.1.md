# ordstack 0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `ordstack` 0.1: stack-allocated containers (`Stack`, `Frame`, `SVec`, `SString`, `SBox`, `SSlice`, `SStr`, `SFixedVec`) where the borrow checker proves that only the top block grows, with the soundness evidence the spec requires.

**Architecture:** One mapped region per `Stack` with a single `top` offset. A `Frame` is a cursor obtained by mutably borrowing whatever lies beneath it; growable containers hold their frame exclusively; frozen handles carry the frame's brand lifetime. Reclamation is lazy: every `&mut` use of an object first resets `top` to that object's end. Only `stack.rs` writes `top`; only `region.rs` talks to the OS.

**Tech Stack:** Rust (edition 2024, MSRV 1.85, stable), `libc`; dev: `trybuild`, `proptest`, `cargo-fuzz`, Miri, AddressSanitizer.

**Spec:** `docs/superpowers/specs/2026-10-13-ordstack-design.md` (read it before any task).

## Review Focus

Conditions the spec implies that are most likely to bite a user. Each has a test in the named task.

1. **A forgotten child.** `mem::forget` of a container or sub-frame, then growing the parent: the parent must reclaim the space and stay uncorrupted. (Task 6, `forgotten_child_is_reclaimed`)
2. **Exhaustion mid-growth.** `try_push` on a full stack returns the value and leaves length, capacity and `extent` unchanged, and the vector still works. (Task 6, `failed_growth_changes_nothing`)
3. **Over-aligned elements after odd-sized blocks**, including freezing an empty over-aligned vector: padding must not be counted into the frame or leak into a neighbour. (Task 6, `overaligned_after_odd_block`)
4. **Zero-size elements** in every container: millions of pushes use no space, and each is dropped exactly once. (Task 6, `zst_elements`)
5. **A panicking destructor or `Clone`** in the middle of a container: no double drop, and the stack is usable afterwards. (Task 10)

//! Allocation failure.

use core::fmt;

/// Why an allocation failed.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
#[non_exhaustive]
pub enum AllocErrorKind {
    /// The stack's reservation is used up.
    Exhausted,
    /// The requested size overflows `usize` or exceeds `isize::MAX`.
    CapacityOverflow,
    /// The requested alignment is above 4096.
    AlignTooLarge,
    /// The operating system refused the mapping.
    MapFailed,
}

/// An allocation on a [`Stack`](crate::Stack) failed.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct AllocError {
    kind: AllocErrorKind,
}

impl AllocError {
    pub(crate) const fn new(kind: AllocErrorKind) -> AllocError {
        AllocError { kind }
    }

    /// The reason for the failure.
    pub fn kind(&self) -> AllocErrorKind {
        self.kind
    }
}

impl fmt::Display for AllocError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.write_str(match self.kind {
            AllocErrorKind::Exhausted => "stack reservation exhausted",
            AllocErrorKind::CapacityOverflow => "capacity overflow",
            AllocErrorKind::AlignTooLarge => "alignment above 4096 is not supported",
            AllocErrorKind::MapFailed => "the operating system refused the mapping",
        })
    }
}

impl std::error::Error for AllocError {}

/// The single panic path of every infallible allocating method.
#[cold]
#[inline(never)]
#[track_caller]
pub(crate) fn fail(e: AllocError) -> ! {
    panic!("ordstack: {e}")
}

//! The operating-system mapping behind a stack. The only module that calls
//! `libc`. It knows nothing about blocks.

use core::ptr::NonNull;

use crate::error::{AllocError, AllocErrorKind};

/// Largest supported block alignment. The region's base is aligned to it.
pub(crate) const MAX_ALIGN: usize = 4096;

/// A reserved, readable and writable address range.
pub(crate) struct Region {
    base: NonNull<u8>,
    len: usize,
}

impl Region {
    /// Reserves `bytes` rounded up to whole pages. Zero bytes maps nothing.
    pub(crate) fn reserve(bytes: usize) -> Result<Region, AllocError> {
        let page = os::page_size();
        let len = bytes
            .checked_add(page - 1)
            .map(|b| b & !(page - 1))
            .filter(|&b| b <= isize::MAX as usize - page)
            .ok_or(AllocError::new(AllocErrorKind::CapacityOverflow))?;
        if len == 0 {
            let base = NonNull::new(core::ptr::without_provenance_mut(MAX_ALIGN)).unwrap();
            return Ok(Region { base, len: 0 });
        }
        let base = os::map(len).ok_or(AllocError::new(AllocErrorKind::MapFailed))?;
        debug_assert_eq!(base.as_ptr() as usize % MAX_ALIGN, 0);
        Ok(Region { base, len })
    }

    pub(crate) fn base(&self) -> NonNull<u8> {
        self.base
    }

    pub(crate) fn len(&self) -> usize {
        self.len
    }

    /// Returns the whole pages at or above offset `from` to the OS. The range
    /// stays mapped; its contents become unspecified.
    pub(crate) fn release_pages(&self, from: usize) {
        let page = os::page_size();
        let Some(start) = from.checked_add(page - 1).map(|b| b & !(page - 1)) else {
            return;
        };
        if start >= self.len {
            return;
        }
        // SAFETY: `start < len`, so the range lies inside our mapping, and
        // `start` is page aligned because the base is.
        unsafe { os::discard(self.base.add(start), self.len - start) };
    }
}

impl Drop for Region {
    fn drop(&mut self) {
        if self.len > 0 {
            // SAFETY: `base`/`len` are exactly what `os::map` returned.
            unsafe { os::unmap(self.base, self.len) };
        }
    }
}

#[cfg(all(unix, not(miri)))]
mod os {
    use core::ptr::NonNull;

    pub(super) fn page_size() -> usize {
        // SAFETY: `sysconf` has no preconditions.
        let p = unsafe { libc::sysconf(libc::_SC_PAGESIZE) };
        (p.max(1) as usize).max(super::MAX_ALIGN)
    }

    pub(super) fn map(len: usize) -> Option<NonNull<u8>> {
        // SAFETY: an anonymous private mapping at a kernel-chosen address
        // touches no existing memory.
        let p = unsafe {
            libc::mmap(
                core::ptr::null_mut(),
                len,
                libc::PROT_READ | libc::PROT_WRITE,
                libc::MAP_PRIVATE | libc::MAP_ANONYMOUS | libc::MAP_NORESERVE,
                -1,
                0,
            )
        };
        if p == libc::MAP_FAILED { None } else { NonNull::new(p.cast()) }
    }

    /// # Safety
    /// `base`/`len` must be a live mapping returned by [`map`].
    pub(super) unsafe fn unmap(base: NonNull<u8>, len: usize) {
        // SAFETY: guaranteed by the caller.
        unsafe { libc::munmap(base.as_ptr().cast(), len) };
    }

    /// # Safety
    /// The page-aligned range must lie inside a live mapping from [`map`],
    /// and nothing may rely on its contents.
    pub(super) unsafe fn discard(start: NonNull<u8>, len: usize) {
        #[cfg(any(target_os = "linux", target_os = "android"))]
        const ADVICE: libc::c_int = libc::MADV_DONTNEED;
        #[cfg(not(any(target_os = "linux", target_os = "android")))]
        const ADVICE: libc::c_int = libc::MADV_FREE;
        // SAFETY: guaranteed by the caller. A failure only means the pages
        // were not returned, which is not an error for us.
        unsafe { libc::madvise(start.as_ptr().cast(), len, ADVICE) };
    }
}

// Miri rejects MAP_NORESERVE, so the region is a heap block there.
#[cfg(miri)]
mod os {
    use core::ptr::NonNull;
    use std::alloc::{Layout, alloc, dealloc};

    pub(super) fn page_size() -> usize {
        super::MAX_ALIGN
    }

    pub(super) fn map(len: usize) -> Option<NonNull<u8>> {
        let layout = Layout::from_size_align(len, super::MAX_ALIGN).ok()?;
        // SAFETY: `len > 0` is checked by the caller.
        NonNull::new(unsafe { alloc(layout) })
    }

    /// # Safety
    /// `base`/`len` must be a live block returned by [`map`].
    pub(super) unsafe fn unmap(base: NonNull<u8>, len: usize) {
        let layout = Layout::from_size_align(len, super::MAX_ALIGN).unwrap();
        // SAFETY: guaranteed by the caller.
        unsafe { dealloc(base.as_ptr(), layout) };
    }

    /// # Safety
    /// None under Miri: this is a no-op.
    pub(super) unsafe fn discard(_start: NonNull<u8>, _len: usize) {}
}

```rust
//! Debug-build shadow. Each thread keeps a table of its live regions and
//! their current `top`. Handles assert on every access that their block lies
//! below `top`; a failure means memory was reclaimed while still reachable,
//! which is a soundness bug in this crate. Release builds compile all of
//! this to nothing.

#[cfg(debug_assertions)]
mod imp {
    use std::cell::RefCell;

    struct Entry {
        base: usize,
        cap: usize,
        top: usize,
    }

    thread_local! {
        static REGIONS: RefCell<Vec<Entry>> = const { RefCell::new(Vec::new()) };
    }

    pub(crate) fn register(base: usize, cap: usize) {
        if cap == 0 {
            return;
        }
        let _ = REGIONS.try_with(|r| r.borrow_mut().push(Entry { base, cap, top: 0 }));
    }

    pub(crate) fn unregister(base: usize) {
        let _ = REGIONS.try_with(|r| r.borrow_mut().retain(|e| e.base != base));
    }

    pub(crate) fn set_top(base: usize, top: usize) {
        let _ = REGIONS.try_with(|r| {
            if let Some(e) = r.borrow_mut().iter_mut().find(|e| e.base == base) {
                e.top = top;
            }
        });
    }

    pub(crate) fn check_live(addr: *const u8, bytes: usize) {
        if bytes == 0 {
            return;
        }
        let addr = addr as usize;
        let _ = REGIONS.try_with(|r| {
            let r = r.borrow();
            let e = r
                .iter()
                .find(|e| addr >= e.base && addr < e.base + e.cap)
                .expect("ordstack: internal error: block outside every live stack");
            assert!(
                addr - e.base + bytes <= e.top,
                "ordstack: internal error: block used after its memory was reclaimed"
            );
        });
    }
}

#[cfg(not(debug_assertions))]
mod imp {
    #[inline(always)]
    pub(crate) fn register(_base: usize, _cap: usize) {}
    #[inline(always)]
    pub(crate) fn unregister(_base: usize) {}
    #[inline(always)]
    pub(crate) fn set_top(_base: usize, _top: usize) {}
    #[inline(always)]
    pub(crate) fn check_live(_addr: *const u8, _bytes: usize) {}
}

pub(crate) use imp::*;

#[cfg(all(test, debug_assertions))]
mod tests {
    use super::*;

    #[test]
    fn live_block_passes() {
        register(0x10_0000, 4096);
        set_top(0x10_0000, 64);
        check_live(0x10_0000 as *const u8, 64);
        check_live(0x10_0020 as *const u8, 0);
        unregister(0x10_0000);
    }

    #[should_panic(expected = "reclaimed")]

}

```rust
//! [`Stack`] and the primitives that move `top`. This is the only module
//! that writes `top`.

use core::cell::Cell;
use core::fmt;
use core::ptr::NonNull;

use crate::debug;
use crate::error::{AllocError, AllocErrorKind, fail};
use crate::region::{MAX_ALIGN, Region};

/// Address space reserved by [`Stack::new`].
#[cfg(target_pointer_width = "64")]
pub const DEFAULT_RESERVE: usize = 4 << 30;
/// Address space reserved by [`Stack::new`].
#[cfg(not(target_pointer_width = "64"))]
pub const DEFAULT_RESERVE: usize = 64 << 20;

/// One contiguous address range with a single bump offset.
///
/// A stack hands out memory only through a [`Frame`](crate::Frame). It is
/// neither `Send` nor `Sync`.
pub struct Stack {
    region: Region,
    /// Every live block lies in `[0, top)`.
    top: Cell<usize>,
    high: Cell<usize>,
}

impl Stack {
    /// Reserves [`DEFAULT_RESERVE`] bytes of address space. Pages are
    /// committed by the kernel when first touched.
    ///
    /// # Panics
    /// If the mapping fails.
    pub fn new() -> Stack {
        Stack::with_reserve(DEFAULT_RESERVE)
    }

    /// Reserves `bytes`, rounded up to whole pages.
    ///
    /// # Panics
    /// If the mapping fails.
    pub fn with_reserve(bytes: usize) -> Stack {
        Stack::try_with_reserve(bytes).unwrap_or_else(|e| fail(e))
    }

    /// Reserves `bytes`, rounded up to whole pages.
    pub fn try_with_reserve(bytes: usize) -> Result<Stack, AllocError> {
        let region = Region::reserve(bytes)?;
        debug::register(region.base().as_ptr() as usize, region.len());
        Ok(Stack { region, top: Cell::new(0), high: Cell::new(0) })
    }

    /// Reclaims everything on the stack now. Taking `&mut self` proves that
    /// no frame, container or block of this stack is still alive.
    pub fn reset(&mut self) {
        self.reset_to(0);
    }

    /// Reclaims everything and returns the stack's pages to the OS. The
    /// reservation itself is kept.
    pub fn trim(&mut self) {
        self.reset_to(0);
        self.release_above(0);
    }

    /// Size of the reservation in bytes.
    pub fn capacity(&self) -> usize {
        self.region.len()
    }

    /// Bytes currently in use, including space that will be reclaimed lazily.
    pub fn extent(&self) -> usize {
        self.top.get()
    }

    /// Largest [`extent`](Self::extent) reached so far.
    pub fn high_water(&self) -> usize {
        self.high.get()
    }

    fn set_top(&self, top: usize) {
        self.top.set(top);
        if top > self.high.get() {
            self.high.set(top);
        }
        debug::set_top(self.region.base().as_ptr() as usize, top);
    }

    /// Reset on reacquire. The caller holds `&mut` to the object whose end
    /// is `off`, so by invariant I nothing above `off` is reachable.
    pub(crate) fn reset_to(&self, off: usize) {
        debug_assert!(off <= self.top.get(), "ordstack: internal error: reset above top");
        if self.top.get() > off {
            self.set_top(off);
        }
    }

    /// Allocates an aligned block at `top`; returns its start offset.
    pub(crate) fn try_bump(&self, size: usize, align: usize) -> Result<usize, AllocError> {
        debug_assert!(align.is_power_of_two());
        if align > MAX_ALIGN {
            return Err(AllocError::new(AllocErrorKind::AlignTooLarge));
        }
        let overflow = AllocError::new(AllocErrorKind::CapacityOverflow);
        let start = self.top.get().checked_add(align - 1).ok_or(overflow)? & !(align - 1);
        let end = start.checked_add(size).ok_or(overflow)?;
        if end > self.region.len() {
            return Err(AllocError::new(AllocErrorKind::Exhausted));
        }
        self.set_top(end);
        Ok(start)
    }

    /// Grows the top block, which currently ends at `old_end`, to `new_end`.
    pub(crate) fn try_extend(&self, old_end: usize, new_end: usize) -> Result<(), AllocError> {
        debug_assert_eq!(old_end, self.top.get(), "ordstack: internal error: grow of a non-top block");
        debug_assert!(new_end >= old_end);
        if new_end > self.region.len() {
            return Err(AllocError::new(AllocErrorKind::Exhausted));
        }
        self.set_top(new_end);
        Ok(())
    }

    pub(crate) fn ptr_at(&self, off: usize) -> NonNull<u8> {
        debug_assert!(off <= self.region.len());
        // SAFETY: `off <= len`, so the result is inside or one past the region.
        unsafe { self.region.base().add(off) }
    }

    pub(crate) fn offset_of(&self, p: NonNull<u8>) -> usize {
        let off = p.as_ptr() as usize - self.region.base().as_ptr() as usize;
        debug_assert!(off <= self.region.len());
        off
    }

    pub(crate) fn release_above(&self, off: usize) {
        debug_assert!(off >= self.top.get());
        self.region.release_pages(off);
    }
}

impl Default for Stack {
    fn default() -> Stack {
        Stack::new()
    }
}

impl fmt::Debug for Stack {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.debug_struct("Stack")
            .field("capacity", &self.capacity())
            .field("extent", &self.extent())
            .field("high_water", &self.high_water())
            .finish()
    }
}

impl Drop for Stack {
    fn drop(&mut self) {
        debug::unregister(self.region.base().as_ptr() as usize);
    }
}

//! Trait impls that delegate to a handle's `Deref` target.

/// `deref_traits!([generics] Type, Target)` implements `Debug`, `PartialEq`,
/// `Eq`, `PartialOrd`, `Ord`, `Hash` and `Borrow<Target>` by delegation.

    ([$($g:tt)*] $ty:ty, $target:ty) => {
        impl<$($g)*> core::fmt::Debug for $ty where $target: core::fmt::Debug {
            fn fmt(&self, f: &mut core::fmt::Formatter<'_>) -> core::fmt::Result {
                core::fmt::Debug::fmt(&**self, f)
            }
        }

            fn eq(&self, other: &Self) -> bool {
                **self == **other
            }
        }
        impl<$($g)*> Eq for $ty where $target: Eq {}
        impl<$($g)*> PartialOrd for $ty where $target: PartialOrd {
            fn partial_cmp(&self, other: &Self) -> Option<core::cmp::Ordering> {
                PartialOrd::partial_cmp(&**self, &**other)
            }
        }
        impl<$($g)*> Ord for $ty where $target: Ord {

                Ord::cmp(&**self, &**other)
            }
        }
        impl<$($g)*> core::hash::Hash for $ty where $target: core::hash::Hash {

                core::hash::Hash::hash(&**self, state)
            }
        }

```rust
//! [`Frame`], the allocation cursor.

use core::mem::{align_of, size_of};
use core::ptr::NonNull;

use crate::boxed::SBox;
use crate::error::{AllocError, AllocErrorKind, fail};
use crate::stack::Stack;

/// An allocation cursor above some lower object.
///
/// A frame is obtained by mutably borrowing the stack ([`Stack::frame`]),
/// another frame ([`Frame::sub`]) or a growable container (`above`). The
/// lower object stays mutably borrowed, and therefore frozen, for `'f`.
/// Blocks allocated through the frame are branded `'f`.
///
/// A frame has no destructor. Its memory is reclaimed the next time the
/// object beneath it is used.
pub struct Frame<'f> {
    pub(crate) st: &'f Stack,
    /// Everything this frame has allocated lies below `end`.
    pub(crate) end: usize,
}

impl<'f> Frame<'f> {
    /// A frame above this one. This frame is frozen while the sub-frame, or
    /// anything allocated through it, is alive.
    pub fn sub(&mut self) -> Frame<'_> {
        self.st.reset_to(self.end);
        Frame { st: self.st, end: self.end }
    }

    /// Reclaims everything above this frame now instead of at its next use.
    pub fn reset_above(&mut self) {
        self.st.reset_to(self.end);
    }

    /// Reclaims everything above this frame and returns those pages to the OS.
    pub fn trim_above(&mut self) {
        self.st.reset_to(self.end);
        self.st.release_above(self.end);
    }

    /// Offset of this frame's end from the base of its stack.
    pub fn end_offset(&self) -> usize {
        self.end
    }

    /// An uninitialised block for `n` values of `T`, owned by this frame.
    /// Returns a dangling pointer when the block has zero size.
    pub(crate) fn try_alloc_array<T>(&mut self, n: usize) -> Result<NonNull<T>, AllocError> {
        let bytes = size_of::<T>()
            .checked_mul(n)
            .ok_or(AllocError::new(AllocErrorKind::CapacityOverflow))?;
        if bytes == 0 {
            return Ok(NonNull::dangling());
        }
        // `&mut self` proves nothing above `end` is reachable (invariant I).
        self.st.reset_to(self.end);
        let start = self.st.try_bump(bytes, align_of::<T>())?;
        self.end = start + bytes;
        Ok(self.st.ptr_at(start).cast())
    }

    /// Moves `value` into a frozen block.
    ///
    /// # Panics
    /// If the stack is exhausted or `T`'s alignment is above 4096.
    pub fn alloc<T>(&mut self, value: T) -> SBox<'f, T> {
        self.try_alloc(value).unwrap_or_else(|e| fail(e))
    }

    /// Moves `value` into a frozen block, or drops it and reports why not.
    pub fn try_alloc<T>(&mut self, value: T) -> Result<SBox<'f, T>, AllocError> {
        let p = self.try_alloc_array::<T>(1)?;
        // SAFETY: `p` is a fresh, aligned block for one `T` (or dangling and
        // aligned for a zero-size `T`), below `self.end`, which does not
        // decrease while `'f` is alive.
        unsafe {
            p.as_ptr().write(value);
            Ok(SBox::from_raw(p))
        }
    }

    /// Like [`alloc`](Self::alloc), with the value built by `f`. `f` runs
    /// before any space is reserved.
    pub fn alloc_with<T>(&mut self, f: impl FnOnce() -> T) -> SBox<'f, T> {
        let value = f();
        self.alloc(value)
    }
}

```rust
//! [`SBox`], an owning pointer to one frozen value.

use core::marker::PhantomData;
use core::mem::{ManuallyDrop, size_of};
use core::ops::{Deref, DerefMut};
use core::ptr::NonNull;

use crate::debug;
use crate::macros::deref_traits;

/// An owning pointer to a value in a frozen block.
///
/// Dropping the box drops the value. The bytes are reclaimed with the frame.
pub struct SBox<'f, T> {
    ptr: NonNull<T>,
    _brand: PhantomData<(&'f (), T)>,
}

impl<'f, T> SBox<'f, T> {
    /// # Safety
    /// `ptr` must point to an initialised `T` in a block that stays allocated
    /// and unaliased for `'f` (or be dangling and aligned if `T` is
    /// zero-size, with one logical `T` owned).
    pub(crate) unsafe fn from_raw(ptr: NonNull<T>) -> SBox<'f, T> {
        SBox { ptr, _brand: PhantomData }
    }

    fn check(&self) {
        debug::check_live(self.ptr.as_ptr().cast(), size_of::<T>());
    }

    /// Moves the value out. Its bytes stay allocated until the frame is
    /// reclaimed.
    pub fn into_inner(this: SBox<'f, T>) -> T {
        this.check();
        let this = ManuallyDrop::new(this);
        // SAFETY: the box owns an initialised `T` and is never used again.
        unsafe { this.ptr.as_ptr().read() }
    }

    /// Gives up ownership and returns a reference valid for the brand. The
    /// value's destructor will not run.
    pub fn leak(this: SBox<'f, T>) -> &'f mut T
    where
        T: 'f,
    {
        this.check();
        let this = ManuallyDrop::new(this);
        // SAFETY: the block is allocated and unaliased for `'f`, and the
        // forgotten box was its only owner.
        unsafe { &mut *this.ptr.as_ptr() }
    }
}

impl<T> Deref for SBox<'_, T> {
    type Target = T;
    fn deref(&self) -> &T {
        self.check();
        // SAFETY: initialised and alive for the brand.
        unsafe { self.ptr.as_ref() }
    }
}

impl<T> DerefMut for SBox<'_, T> {
    fn deref_mut(&mut self) -> &mut T {
        self.check();
        // SAFETY: as above, and the box is the unique owner.
        unsafe { self.ptr.as_mut() }
    }
}

impl<T> Drop for SBox<'_, T> {
    fn drop(&mut self) {
        self.check();
        // SAFETY: unique owner of an initialised value; never used again.
        unsafe { core::ptr::drop_in_place(self.ptr.as_ptr()) };
    }
}

deref_traits!(['f, T] SBox<'f, T>, T);

//! [`SSlice`] and [`SStr`], owning frozen slices.

use core::fmt;
use core::marker::PhantomData;
use core::mem::{ManuallyDrop, size_of};
use core::ops::{Deref, DerefMut};
use core::ptr::NonNull;

use crate::debug;
use crate::macros::deref_traits;

/// Drops the `len` values starting at `ptr`, last first. If a destructor
/// panics, the remaining values are still dropped during unwinding; a second
/// panic aborts.
///
/// # Safety
/// `ptr` must point to `len` initialised values that the caller owns and
/// will not touch again.
pub(crate) unsafe fn drop_back_to_front<T>(ptr: *mut T, len: usize) {
    struct Rest<T> {
        ptr: *mut T,
        left: usize,
    }
    impl<T> Rest<T> {
        fn run(&mut self) {
            while self.left > 0 {
                self.left -= 1;
                // SAFETY: index `left` is below the original length and is
                // visited once, because `left` is lowered before the drop.
                unsafe { core::ptr::drop_in_place(self.ptr.add(self.left)) };
            }
        }
    }
    impl<T> Drop for Rest<T> {
        fn drop(&mut self) {
            self.run();
        }
    }
    Rest { ptr, left: len }.run();
}

/// An owning slice in a frozen block. Elements are dropped back to front.
pub struct SSlice<'f, T> {
    ptr: NonNull<T>,
    len: usize,
    _brand: PhantomData<(&'f (), T)>,
}

impl<'f, T> SSlice<'f, T> {
    /// An empty slice. Allocates nothing.
    pub const fn empty() -> SSlice<'f, T> {
        SSlice { ptr: NonNull::dangling(), len: 0, _brand: PhantomData }
    }

    /// # Safety
    /// `ptr` must point to `len` initialised values in a block that stays
    /// allocated and unaliased for `'f` (or be dangling and aligned when
    /// `len * size_of::<T>() == 0`).
    pub(crate) unsafe fn from_raw_parts(ptr: NonNull<T>, len: usize) -> SSlice<'f, T> {
        SSlice { ptr, len, _brand: PhantomData }
    }

    fn check(&self) {
        debug::check_live(self.ptr.as_ptr().cast(), self.len * size_of::<T>());
    }

    /// Gives up ownership and returns a reference valid for the brand. The
    /// elements' destructors will not run.
    pub fn leak(this: SSlice<'f, T>) -> &'f mut [T]
    where
        T: 'f,
    {
        this.check();
        let this = ManuallyDrop::new(this);
        // SAFETY: allocated, initialised and unaliased for `'f`.
        unsafe { core::slice::from_raw_parts_mut(this.ptr.as_ptr(), this.len) }
    }
}

impl<T> Deref for SSlice<'_, T> {
    type Target = [T];
    fn deref(&self) -> &[T] {
        self.check();
        // SAFETY: `len` initialised values, alive for the brand.
        unsafe { core::slice::from_raw_parts(self.ptr.as_ptr(), self.len) }
    }
}

impl<T> DerefMut for SSlice<'_, T> {
    fn deref_mut(&mut self) -> &mut [T] {
        self.check();
        // SAFETY: as above, and the slice is the unique owner.
        unsafe { core::slice::from_raw_parts_mut(self.ptr.as_ptr(), self.len) }
    }
}

impl<T> Drop for SSlice<'_, T> {
    fn drop(&mut self) {
        self.check();
        let len = core::mem::replace(&mut self.len, 0);
        // SAFETY: we own `len` initialised values and `self.len` is now 0.
        unsafe { drop_back_to_front(self.ptr.as_ptr(), len) };
    }
}

deref_traits!(['f, T] SSlice<'f, T>, [T]);

/// By-value iterator over an [`SSlice`]. Elements not yet yielded are
/// dropped back to front when the iterator is dropped.
pub struct IntoIter<'f, T> {
    ptr: NonNull<T>,
    head: usize,
    tail: usize,
    _brand: PhantomData<(&'f (), T)>,
}

impl<'f, T> IntoIterator for SSlice<'f, T> {
    type Item = T;
    type IntoIter = IntoIter<'f, T>;
    fn into_iter(self) -> IntoIter<'f, T> {
        self.check();
        let this = ManuallyDrop::new(self);
        IntoIter { ptr: this.ptr, head: 0, tail: this.len, _brand: PhantomData }
    }
}

impl<T> Iterator for IntoIter<'_, T> {
    type Item = T;
    fn next(&mut self) -> Option<T> {
        if self.head == self.tail {
            return None;
        }
        self.head += 1;
        // SAFETY: index `head - 1` is initialised and is never read again.
        Some(unsafe { self.ptr.as_ptr().add(self.head - 1).read() })
    }
    fn size_hint(&self) -> (usize, Option<usize>) {
        let n = self.tail - self.head;
        (n, Some(n))
    }
}

impl<T> DoubleEndedIterator for IntoIter<'_, T> {
    fn next_back(&mut self) -> Option<T> {
        if self.head == self.tail {
            return None;
        }
        self.tail -= 1;
        // SAFETY: index `tail` is initialised and is never read again.
        Some(unsafe { self.ptr.as_ptr().add(self.tail).read() })
    }
}

impl<T> ExactSizeIterator for IntoIter<'_, T> {}

impl<T> Drop for IntoIter<'_, T> {
    fn drop(&mut self) {
        let (head, n) = (self.head, self.tail - self.head);
        self.tail = self.head;
        // SAFETY: `[head, head + n)` are the initialised values not yet
        // yielded, and the bounds were just emptied.
        unsafe { drop_back_to_front(self.ptr.as_ptr().add(head), n) };
    }
}

    /// Copies `src` into a frozen block.
    ///
    /// # Panics
    /// If the stack is exhausted.
    pub fn alloc_slice_copy<T: Copy>(&mut self, src: &[T]) -> SSlice<'f, T> {
        let p = self.try_alloc_array::<T>(src.len()).unwrap_or_else(|e| fail(e));
        // SAFETY: `p` is a fresh block for `src.len()` values, disjoint from
        // `src`; `T: Copy`, so a bitwise copy initialises it.
        unsafe {
            core::ptr::copy_nonoverlapping(src.as_ptr(), p.as_ptr(), src.len());
            SSlice::from_raw_parts(p, src.len())
        }
    }

    /// Clones `src` into a frozen block. If a `clone` panics, the clones made
    /// so far are dropped; the block's space stays with this frame.
    ///
    /// # Panics
    /// If the stack is exhausted.
    pub fn alloc_slice_clone<T: Clone>(&mut self, src: &[T]) -> SSlice<'f, T> {
        struct Done<T> {
            ptr: *mut T,
            n: usize,
        }
        impl<T> Drop for Done<T> {
            fn drop(&mut self) {
                // SAFETY: the first `n` slots were initialised by the loop.
                unsafe { drop_back_to_front(self.ptr, self.n) };
            }
        }
        let p = self.try_alloc_array::<T>(src.len()).unwrap_or_else(|e| fail(e));
        let mut done = Done { ptr: p.as_ptr(), n: 0 };
        for x in src {
            // SAFETY: slot `n < src.len()` is inside the fresh block and
            // uninitialised.
            unsafe { done.ptr.add(done.n).write(x.clone()) };
            done.n += 1;
        }
        core::mem::forget(done);
        // SAFETY: all `src.len()` slots are initialised.
        unsafe { SSlice::from_raw_parts(p, src.len()) }
    }

    /// Copies `src` into a frozen block.
    ///
    /// # Panics
    /// If the stack is exhausted.
    pub fn alloc_str(&mut self, src: &str) -> SStr<'f> {
        // SAFETY: the bytes come from a `str`.
        unsafe { SStr::from_utf8_unchecked(self.alloc_slice_copy(src.as_bytes())) }
    }

//! [`SFixedVec`], a vector with a capacity fixed at creation.

use core::marker::PhantomData;
use core::mem::{ManuallyDrop, size_of};
use core::ops::{Deref, DerefMut};
use core::ptr::NonNull;

use crate::debug;
use crate::error::fail;
use crate::frame::Frame;
use crate::macros::deref_traits;
use crate::slice::{SSlice, drop_back_to_front};

/// A vector whose capacity is fixed when it is created.
///
/// It is a frozen block: unlike [`SVec`](crate::SVec) it does not hold its
/// frame, so the frame can allocate above it while it is being filled.
pub struct SFixedVec<'f, T> {
    ptr: NonNull<T>,
    len: usize,
    cap: usize,
    _brand: PhantomData<(&'f (), T)>,
}

impl<'f, T> SFixedVec<'f, T> {
    /// Reserves a block for `cap` elements.
    ///
    /// # Panics
    /// If the stack is exhausted.
    pub fn with_capacity_in(cap: usize, frame: &mut Frame<'f>) -> SFixedVec<'f, T> {
        let ptr = frame.try_alloc_array::<T>(cap).unwrap_or_else(|e| fail(e));
        SFixedVec { ptr, len: 0, cap, _brand: PhantomData }
    }

    fn check(&self) {
        debug::check_live(self.ptr.as_ptr().cast(), self.cap * size_of::<T>());
    }

    /// The number of elements the vector can hold.
    pub fn capacity(&self) -> usize {
        self.cap
    }

    /// Whether the vector is at capacity.
    pub fn is_full(&self) -> bool {
        self.len == self.cap
    }

    /// Appends `value`.
    ///
    /// # Panics
    /// If the vector is full.
    pub fn push(&mut self, value: T) {
        if self.try_push(value).is_err() {
            panic!("ordstack: SFixedVec capacity exceeded");
        }
    }

    /// Appends `value`, or returns it if the vector is full.
    pub fn try_push(&mut self, value: T) -> Result<(), T> {
        if self.len == self.cap {
            return Err(value);
        }
        self.check();
        // SAFETY: `len < cap`: the slot is inside the block and uninitialised.
        unsafe { self.ptr.as_ptr().add(self.len).write(value) };
        self.len += 1;
        Ok(())
    }

    /// Removes and returns the last element.
    pub fn pop(&mut self) -> Option<T> {
        if self.len == 0 {
            return None;
        }
        self.check();
        self.len -= 1;
        // SAFETY: the slot was initialised and is now outside `[0, len)`.
        Some(unsafe { self.ptr.as_ptr().add(self.len).read() })
    }

    /// Converts into a frozen slice of the elements pushed so far. Unused
    /// capacity is not reclaimed.
    pub fn into_slice(self) -> SSlice<'f, T> {
        let this = ManuallyDrop::new(self);
        // SAFETY: `len` initialised values in a block allocated for `'f`.
        unsafe { SSlice::from_raw_parts(this.ptr, this.len) }
    }
}

impl<T> Deref for SFixedVec<'_, T> {
    type Target = [T];
    fn deref(&self) -> &[T] {
        self.check();
        // SAFETY: `len` initialised values.
        unsafe { core::slice::from_raw_parts(self.ptr.as_ptr(), self.len) }
    }
}

impl<T> DerefMut for SFixedVec<'_, T> {
    fn deref_mut(&mut self) -> &mut [T] {
        self.check();
        // SAFETY: `len` initialised values; unique owner.
        unsafe { core::slice::from_raw_parts_mut(self.ptr.as_ptr(), self.len) }
    }
}

impl<T> Drop for SFixedVec<'_, T> {
    fn drop(&mut self) {
        self.check();
        let len = core::mem::replace(&mut self.len, 0);
        // SAFETY: we own `len` initialised values and `self.len` is now 0.
        unsafe { drop_back_to_front(self.ptr.as_ptr(), len) };
    }
}

/// A tree whose parent's child list grows: children are collected on a
/// scratch stack and copied once into the tree's stack.
struct Node<'t> {
    id: u32,
    kids: SSlice<'t, Node<'t>>,
}

fn grow<'t>(tree: &mut Frame<'t>, scratch: &mut Frame<'_>, depth: u32, next: &mut u32) -> Node<'t> {
    let id = *next;
    *next += 1;
    let mut kids: SVec<Node<'t>> = SVec::new_in(scratch);
    for _ in 0..depth {
        let (_, mut above) = kids.split_above();
        let kid = grow(tree, &mut above, depth - 1, next);
        kids.push(kid);
    }
    Node { id, kids: kids.freeze_into(tree) }
}

fn sum(n: &Node<'_>) -> u32 {
    n.id + n.kids.iter().map(sum).sum::<u32>()
}

```rust
//! [`SVec`], the growable vector.

use core::marker::PhantomData;
use core::mem::{ManuallyDrop, align_of, size_of};
use core::ops::{Deref, DerefMut};
use core::ptr::NonNull;

use crate::debug;
use crate::error::{AllocError, AllocErrorKind, fail};
use crate::frame::Frame;
use crate::slice::{SSlice, drop_back_to_front};

const OVERFLOW: AllocError = AllocError::new(AllocErrorKind::CapacityOverflow);

/// A growable vector on a stack.
///
/// The vector holds its frame exclusively, so whenever it can be reached
/// mutably its buffer is the top block of the stack and grows in place. To
/// allocate anything else on the same stack, take a frame above the vector
/// with [`above`](Self::above); the vector is frozen until that frame and
/// everything allocated through it are gone.
///
/// Elements are dropped back to front.
pub struct SVec<'v, 'f, T> {
    frame: &'v mut Frame<'f>,
    /// Start of the buffer; dangling while nothing is allocated.
    ptr: NonNull<T>,
    len: usize,
    /// `usize::MAX` for zero-size `T`, which never allocates.
    cap: usize,
    _owns: PhantomData<T>,
}

impl<'v, 'f, T> SVec<'v, 'f, T> {
    const ZST: bool = size_of::<T>() == 0;

    /// An empty vector on top of `frame`. Allocates nothing yet.
    pub fn new_in(frame: &'v mut Frame<'f>) -> SVec<'v, 'f, T> {
        let cap = if Self::ZST { usize::MAX } else { 0 };
        SVec { frame, ptr: NonNull::dangling(), len: 0, cap, _owns: PhantomData }
    }

    /// An empty vector with room for exactly `cap` elements.
    ///
    /// # Panics
    /// If the stack is exhausted.
    pub fn with_capacity_in(cap: usize, frame: &'v mut Frame<'f>) -> SVec<'v, 'f, T> {
        let mut v = SVec::new_in(frame);
        if cap > v.cap {
            v.try_grow_to(cap).unwrap_or_else(|e| fail(e));
        }
        v
    }

    /// Collects `iter` into a vector on top of `frame`.
    pub fn from_iter_in<I: IntoIterator<Item = T>>(iter: I, frame: &'v mut Frame<'f>) -> SVec<'v, 'f, T> {
        let mut v = SVec::new_in(frame);
        v.extend(iter);
        v
    }

    fn allocated(&self) -> bool {
        !Self::ZST && self.cap > 0
    }

    /// Offset of the buffer's start. Only meaningful when allocated.
    fn start_off(&self) -> usize {
        self.frame.st.offset_of(self.ptr.cast())
    }

    /// Offset of the end of this vector: its capacity end, or the frame's
    /// end while nothing is allocated.
    fn end_off(&self) -> usize {
        if self.allocated() {
            self.start_off() + self.cap * size_of::<T>()
        } else {
            self.frame.end
        }
    }

    fn check(&self) {
        debug::check_live(self.ptr.as_ptr().cast(), if Self::ZST { 0 } else { self.cap * size_of::<T>() });
    }

    /// Sets the capacity to `new_cap > self.cap`. Never moves the buffer.
    fn try_grow_to(&mut self, new_cap: usize) -> Result<(), AllocError> {
        debug_assert!(!Self::ZST && new_cap > self.cap);
        let st = self.frame.st;
        let bytes = new_cap.checked_mul(size_of::<T>()).ok_or(OVERFLOW)?;
        let old_end = self.end_off();
        // We hold `&mut self`, so by invariant I nothing above our end is
        // reachable; after this reset our buffer is the top block.
        st.reset_to(old_end);
        if self.allocated() {
            let new_end = self.start_off().checked_add(bytes).ok_or(OVERFLOW)?;
            st.try_extend(old_end, new_end)?;
        } else {
            let start = st.try_bump(bytes, align_of::<T>())?;
            self.ptr = st.ptr_at(start).cast();
        }
        self.cap = new_cap;
        Ok(())
    }

    /// Makes room for at least `additional` more elements.
    ///
    /// # Panics
    /// If the stack is exhausted or the capacity overflows.
    pub fn reserve(&mut self, additional: usize) {
        self.try_reserve(additional).unwrap_or_else(|e| fail(e));
    }

    /// Makes room for at least `additional` more elements. On failure the
    /// vector is unchanged.
    pub fn try_reserve(&mut self, additional: usize) -> Result<(), AllocError> {
        let needed = self.len.checked_add(additional).ok_or(OVERFLOW)?;
        if needed <= self.cap {
            return Ok(());
        }
        // Amortised doubling, falling back to the exact size when the
        // doubled buffer does not fit.
        let doubled = self.cap.saturating_mul(2).max(4);
        if doubled > needed && self.try_grow_to(doubled).is_ok() {
            return Ok(());
        }
        self.try_grow_to(needed)
    }

    /// The number of elements the vector can hold without growing.
    pub fn capacity(&self) -> usize {
        self.cap
    }

    /// Appends `value`.
    ///
    /// # Panics
    /// If the stack is exhausted.
    pub fn push(&mut self, value: T) {
        if let Err((_, e)) = self.try_push(value) {
            fail(e);
        }
    }

    /// Appends `value`, or returns it with the reason it did not fit.
    pub fn try_push(&mut self, value: T) -> Result<(), (T, AllocError)> {
        if self.len == self.cap {
            if let Err(e) = self.try_reserve(1) {
                return Err((value, e));
            }
        }
        self.check();
        // SAFETY: `len < cap`: the slot is inside our buffer and holds no
        // value. For a zero-size `T` the pointer is dangling and aligned.
        unsafe { self.ptr.as_ptr().add(self.len).write(value) };
        self.len += 1;
        Ok(())
    }

    /// Removes and returns the last element.
    pub fn pop(&mut self) -> Option<T> {
        if self.len == 0 {
            return None;
        }
        self.check();
        self.len -= 1;
        // SAFETY: the slot was initialised and is now outside `[0, len)`.
        Some(unsafe { self.ptr.as_ptr().add(self.len).read() })
    }

    /// Appends a copy of every element of `src`.
    ///
    /// # Panics
    /// If the stack is exhausted.
    pub fn extend_from_slice(&mut self, src: &[T])
    where
        T: Copy,
    {
        self.reserve(src.len());
        self.check();
        // SAFETY: `reserve` made room for `src.len()` more values; `src`
        // cannot overlap spare capacity that only `self` can reach.
        unsafe { core::ptr::copy_nonoverlapping(src.as_ptr(), self.ptr.as_ptr().add(self.len), src.len()) };
        self.len += src.len();
    }

    /// Gives unused capacity back to the stack. Never moves the buffer.
    pub fn shrink_to_fit(&mut self) {
        if !self.allocated() {
            return;
        }
        let st = self.frame.st;
        if self.len == 0 {
            st.reset_to(self.frame.end);
            self.ptr = NonNull::dangling();
            self.cap = 0;
        } else {
            st.reset_to(self.start_off() + self.len * size_of::<T>());
            self.cap = self.len;
        }
    }

    /// Freeze and descend: a frame above this vector. The vector cannot be
    /// used until the frame and everything allocated through it are gone.
    pub fn above(&mut self) -> Frame<'_> {
        let end = self.end_off();
        self.frame.st.reset_to(end);
        Frame { st: self.frame.st, end }
    }

    /// Like [`above`](Self::above), but the elements stay readable and
    /// writable. The vector still cannot grow or shrink.
    pub fn split_above(&mut self) -> (&mut [T], Frame<'_>) {
        self.check();
        let end = self.end_off();
        self.frame.st.reset_to(end);
        let frame = Frame { st: self.frame.st, end };
        // SAFETY: `len` initialised values. The frame only hands out memory
        // at or above `end`, which is disjoint from the elements.
        (unsafe { core::slice::from_raw_parts_mut(self.ptr.as_ptr(), self.len) }, frame)
    }

    fn into_parts(self) -> (&'v mut Frame<'f>, NonNull<T>, usize, bool) {
        let allocated = self.allocated();
        let this = ManuallyDrop::new(self);
        // SAFETY: `this` is never used or dropped again, so this moves the
        // unique reference out of it.
        let frame = unsafe { core::ptr::read(&this.frame) };
        (frame, this.ptr, this.len, allocated)
    }

    /// Freezes the vector in place, without copying. Spare capacity goes
    /// back to the stack, and the frame can be used again.
    pub fn freeze(self) -> SSlice<'f, T> {
        self.check();
        let (frame, ptr, len, allocated) = self.into_parts();
        if allocated {
            let st = frame.st;
            if len == 0 {
                st.reset_to(frame.end);
                return SSlice::empty();
            }
            let new_end = st.offset_of(ptr.cast()) + len * size_of::<T>();
            st.reset_to(new_end);
            frame.end = new_end;
        }
        // SAFETY: `len` initialised values now lie below `frame.end`, which
        // does not decrease while `'f` is alive. When nothing is allocated,
        // `len * size_of::<T>() == 0` and `ptr` is dangling and aligned.
        unsafe { SSlice::from_raw_parts(ptr, len) }
    }

    /// Moves the elements into a frozen block of `dst` with one bitwise
    /// copy. This vector's buffer is left to be reclaimed.
    ///
    /// # Panics
    /// If `dst`'s stack is exhausted.
    pub fn freeze_into<'g>(mut self, dst: &mut Frame<'g>) -> SSlice<'g, T> {
        self.check();
        let len = self.len;
        let p = dst.try_alloc_array::<T>(len).unwrap_or_else(|e| fail(e));
        // SAFETY: `p` is a fresh block for `len` values and cannot overlap
        // our buffer. Setting `self.len = 0` hands ownership to the copy.
        unsafe {
            core::ptr::copy_nonoverlapping(self.ptr.as_ptr(), p.as_ptr(), len);
            self.len = 0;
            SSlice::from_raw_parts(p, len)
        }
    }
}

impl<T> Deref for SVec<'_, '_, T> {
    type Target = [T];
    fn deref(&self) -> &[T] {
        self.check();
        // SAFETY: `len` initialised values.
        unsafe { core::slice::from_raw_parts(self.ptr.as_ptr(), self.len) }
    }
}

impl<T> DerefMut for SVec<'_, '_, T> {
    fn deref_mut(&mut self) -> &mut [T] {
        self.check();
        // SAFETY: `len` initialised values; unique owner.
        unsafe { core::slice::from_raw_parts_mut(self.ptr.as_ptr(), self.len) }
    }
}

impl<T> Extend<T> for SVec<'_, '_, T> {
    fn extend<I: IntoIterator<Item = T>>(&mut self, iter: I) {
        let iter = iter.into_iter();
        // A hint that does not fit is not an error; `push` decides.
        let _ = self.try_reserve(iter.size_hint().0);
        for x in iter {
            self.push(x);
        }
    }
}

impl<T> Drop for SVec<'_, '_, T> {
    fn drop(&mut self) {
        self.check();
        let len = core::mem::replace(&mut self.len, 0);
        // SAFETY: we own `len` initialised values and `self.len` is now 0.
        // The buffer itself is reclaimed when the frame is next used.
        unsafe { drop_back_to_front(self.ptr.as_ptr(), len) };
    }
}

        // SAFETY: capacity is at least `len + 1`. The tail `[index, len)` is
        // moved up by one, then the freed slot is written.
        unsafe {
            let p = self.ptr.as_ptr().add(index);
            core::ptr::copy(p, p.add(1), len - index);
            p.write(value);
        }
        self.len = len + 1;
    }

    /// Removes and returns the element at `index`, shifting later elements
    /// down.
    ///
    /// # Panics
    /// If `index >= len`.
    pub fn remove(&mut self, index: usize) -> T {
        let len = self.len;
        assert!(index < len, "ordstack: removal index (is {index}) should be < len (is {len})");
        self.check();
        // SAFETY: `index < len`. The value is read out, then the tail is
        // moved down over its slot.
        unsafe {
            let p = self.ptr.as_ptr().add(index);
            let value = p.read();
            core::ptr::copy(p.add(1), p, len - index - 1);
            self.len = len - 1;
            value
        }
    }

    /// Removes and returns the element at `index`, replacing it with the
    /// last element.
    ///
    /// # Panics
    /// If `index >= len`.
    pub fn swap_remove(&mut self, index: usize) -> T {
        let len = self.len;
        assert!(index < len, "ordstack: swap_remove index (is {index}) should be < len (is {len})");
        self.check();
        // SAFETY: `index < len`. The value is read out and the last element
        // is moved into its slot (a no-op move when they are the same slot).
        unsafe {
            let base = self.ptr.as_ptr();
            let value = base.add(index).read();
            core::ptr::copy(base.add(len - 1), base.add(index), 1);
            self.len = len - 1;
            value
        }
    }

    /// Shortens the vector to `len` elements, dropping the rest back to
    /// front. Does nothing if `len` is not below the current length.
    pub fn truncate(&mut self, len: usize) {
        if len >= self.len {
            return;
        }
        self.check();
        let n = self.len - len;
        self.len = len;
        // SAFETY: `[len, len + n)` were initialised and are now outside the
        // vector's length.
        unsafe { drop_back_to_front(self.ptr.as_ptr().add(len), n) };
    }

    /// Removes every element, dropping them back to front. Keeps the
    /// capacity.
    pub fn clear(&mut self) {
        self.truncate(0);
    }

    /// Keeps the elements for which `keep` returns `true`, preserving their
    /// order. Removed elements are dropped front to back, as they are
    /// visited.
    pub fn retain(&mut self, mut keep: impl FnMut(&T) -> bool) {
        /// On exit, including by panic, closes the gap and restores `len`.
        struct Gap<'a, 'v, 'f, T> {
            v: &'a mut SVec<'v, 'f, T>,
            /// Elements `[0, write)` are kept; `[read, orig)` are unvisited.
            read: usize,
            write: usize,
            orig: usize,
        }
        impl<T> Drop for Gap<'_, '_, '_, T> {
            fn drop(&mut self) {
                let rest = self.orig - self.read;
                // SAFETY: `[read, orig)` are initialised and `[write, read)`
                // holds no values, so the rest moves down over the gap.
                unsafe {
                    let p = self.v.ptr.as_ptr();
                    core::ptr::copy(p.add(self.read), p.add(self.write), rest);
                }
                self.v.len = self.write + rest;
            }
        }

        self.check();
        let orig = core::mem::replace(&mut self.len, 0);
        let mut g = Gap { v: self, read: 0, write: 0, orig };
        while g.read < g.orig {
            let base = g.v.ptr.as_ptr();
            // SAFETY: `read < orig`, so the slot holds an unvisited value.
            let cur = unsafe { base.add(g.read) };
            // If `keep` panics the value is still in the unvisited range.
            // SAFETY: as above; the reference ends before the value moves.
            let kept = keep(unsafe { &*cur });
            g.read += 1;
            if kept {
                // SAFETY: slot `write <= read - 1` holds no value (or is
                // `cur` itself); the value moves there.
                unsafe { core::ptr::copy(cur, base.add(g.write), 1) };
                g.write += 1;
            } else {
                // `read` is already past the value, so a panicking
                // destructor cannot cause a second drop.
                // SAFETY: the value is initialised and never used again.
                unsafe { core::ptr::drop_in_place(cur) };
            }
        }
    }

//! [`SString`], the growable string.

use core::fmt;
use core::ops::Deref;

use crate::error::AllocError;
use crate::frame::Frame;
use crate::macros::deref_traits;
use crate::slice::SStr;
use crate::vec::SVec;

/// A growable UTF-8 string on a stack. See [`SVec`] for the rules; this is
/// an `SVec<u8>` that keeps its bytes valid UTF-8.
pub struct SString<'v, 'f> {
    vec: SVec<'v, 'f, u8>,
}

impl<'v, 'f> SString<'v, 'f> {
    /// An empty string on top of `frame`. Allocates nothing yet.
    pub fn new_in(frame: &'v mut Frame<'f>) -> SString<'v, 'f> {
        SString { vec: SVec::new_in(frame) }
    }

    /// An empty string with room for exactly `cap` bytes.
    ///
    /// # Panics
    /// If the stack is exhausted.
    pub fn with_capacity_in(cap: usize, frame: &'v mut Frame<'f>) -> SString<'v, 'f> {
        SString { vec: SVec::with_capacity_in(cap, frame) }
    }

    /// A copy of `s` on top of `frame`.
    ///
    /// # Panics
    /// If the stack is exhausted.
    pub fn from_str_in(s: &str, frame: &'v mut Frame<'f>) -> SString<'v, 'f> {
        let mut out = SString::with_capacity_in(s.len(), frame);
        out.push_str(s);
        out
    }

    /// Appends `ch`.
    ///
    /// # Panics
    /// If the stack is exhausted.
    pub fn push(&mut self, ch: char) {
        self.push_str(ch.encode_utf8(&mut [0; 4]));
    }

    /// Appends `s`.
    ///
    /// # Panics
    /// If the stack is exhausted.
    pub fn push_str(&mut self, s: &str) {
        self.vec.extend_from_slice(s.as_bytes());
    }

    /// Removes and returns the last character.
    pub fn pop(&mut self) -> Option<char> {
        let ch = self.chars().next_back()?;
        self.vec.truncate(self.vec.len() - ch.len_utf8());
        Some(ch)
    }

    /// Shortens the string to `len` bytes. Does nothing if `len` is not
    /// below the current length.
    ///
    /// # Panics
    /// If `len` is not on a character boundary.
    pub fn truncate(&mut self, len: usize) {
        if len < self.vec.len() {
            assert!(self.is_char_boundary(len), "ordstack: truncate index {len} is not a char boundary");
            self.vec.truncate(len);
        }
    }

    /// Empties the string. Keeps the capacity.
    pub fn clear(&mut self) {
        self.vec.clear();
    }

    /// Makes room for at least `additional` more bytes.
    ///
    /// # Panics
    /// If the stack is exhausted.
    pub fn reserve(&mut self, additional: usize) {
        self.vec.reserve(additional);
    }

    /// Makes room for at least `additional` more bytes. On failure the
    /// string is unchanged.
    pub fn try_reserve(&mut self, additional: usize) -> Result<(), AllocError> {
        self.vec.try_reserve(additional)
    }

    /// The number of bytes the string can hold without growing.
    pub fn capacity(&self) -> usize {
        self.vec.capacity()
    }

    /// A frame above this string; see [`SVec::above`].
    pub fn above(&mut self) -> Frame<'_> {
        self.vec.above()
    }

    /// Like [`above`](Self::above), with the text still readable and
    /// writable in place.
    pub fn split_above(&mut self) -> (&mut str, Frame<'_>) {
        let (bytes, frame) = self.vec.split_above();
        // SAFETY: the bytes are valid UTF-8, and `&mut str` only allows
        // edits that keep them so.
        (unsafe { core::str::from_utf8_unchecked_mut(bytes) }, frame)
    }

    /// Freezes the string in place; see [`SVec::freeze`].
    pub fn freeze(self) -> SStr<'f> {
        // SAFETY: the bytes are valid UTF-8.
        unsafe { SStr::from_utf8_unchecked(self.vec.freeze()) }
    }

    /// Copies the string into a frozen block of `dst`; see
    /// [`SVec::freeze_into`].
    ///
    /// # Panics
    /// If `dst`'s stack is exhausted.
    pub fn freeze_into<'g>(self, dst: &mut Frame<'g>) -> SStr<'g> {
        // SAFETY: the bytes are valid UTF-8.
        unsafe { SStr::from_utf8_unchecked(self.vec.freeze_into(dst)) }
    }
}

impl Deref for SString<'_, '_> {
    type Target = str;
    fn deref(&self) -> &str {
        // SAFETY: every mutation keeps the bytes valid UTF-8.
        unsafe { core::str::from_utf8_unchecked(&self.vec) }
    }
}

impl fmt::Write for SString<'_, '_> {
    fn write_str(&mut self, s: &str) -> fmt::Result {
        self.push_str(s);
        Ok(())
    }
}

impl Extend<char> for SString<'_, '_> {
    fn extend<I: IntoIterator<Item = char>>(&mut self, iter: I) {
        for ch in iter {
            self.push(ch);
        }
    }
}

impl<'a> Extend<&'a str> for SString<'_, '_> {
    fn extend<I: IntoIterator<Item = &'a str>>(&mut self, iter: I) {
        for s in iter {
            self.push_str(s);
        }
    }
}

impl fmt::Display for SString<'_, '_> {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        fmt::Display::fmt(&**self, f)
    }
}

deref_traits!(['v, 'f] SString<'v, 'f>, str);

    next: Cell<u32>,
    dropped: RefCell<Vec<u32>>,
    expected: RefCell<Vec<u32>>,
}

pub struct Tracked<'c> {
    id: u32,
    cx: &'c Cx,
}

impl Drop for Tracked<'_> {
    fn drop(&mut self) {
        self.cx.dropped.borrow_mut().push(self.id);
    }
}

impl Cx {
    fn new() -> Cx {
        Cx { next: Cell::new(0), dropped: RefCell::new(Vec::new()), expected: RefCell::new(Vec::new()) }
    }

    fn make(&self) -> Tracked<'_> {
        let id = self.next.get();
        self.next.set(id + 1);
        Tracked { id, cx: self }
    }

    /// Records that these ids must be dropped next, in this order.
    fn expect(&self, ids: impl IntoIterator<Item = u32>) {
        self.expected.borrow_mut().extend(ids);
    }

    fn finish(&self) {
        let dropped = self.dropped.borrow();
        assert_eq!(*dropped, *self.expected.borrow(), "drop order differs from the model");
        let mut seen = dropped.clone();
        seen.sort_unstable();
        assert!(seen.iter().copied().eq(0..self.next.get()), "a value was dropped twice or never");
    }
}

const MAX_DEPTH: u32 = 6;

fn ids(xs: &[Tracked<'_>]) -> Vec<u32> {
    xs.iter().map(|t| t.id).collect()
}

fn arg(input: &mut dyn Iterator<Item = u8>) -> usize {
    input.next().unwrap_or(0) as usize
}

fn level<'f, 'c>(frame: &mut Frame<'f>, input: &mut dyn Iterator<Item = u8>, depth: u32, cx: &'c Cx) {
    let mut frozen: Vec<(SSlice<'f, Tracked<'c>>, Vec<u32>)> = Vec::new();
    let mut boxes: Vec<(SBox<'f, Tracked<'c>>, u32)> = Vec::new();
    loop {
        let mut v: SVec<'_, 'f, Tracked<'c>> = SVec::new_in(frame);
        let mut m: Vec<u32> = Vec::new();
        let mut freeze = false;
        while let Some(op) = input.next() {
            match op % 16 {
                0..=5 => {
                    let t = cx.make();
                    m.push(t.id);
                    v.push(t);
                }
                6 => match v.pop() {
                    Some(t) => {
                        assert_eq!(m.pop(), Some(t.id));
                        cx.expect([t.id]);
                    }
                    None => assert!(m.is_empty()),
                },
                7 => {
                    let n = arg(input) % (m.len() + 1);
                    cx.expect(m.drain(n..).rev());
                    v.truncate(n);
                }
                8 => {
                    let i = arg(input) % (m.len() + 1);
                    let t = cx.make();
                    m.insert(i, t.id);
                    v.insert(i, t);
                }
                9 => {
                    if !m.is_empty() {
                        let i = arg(input) % m.len();
                        let t = v.remove(i);
                        assert_eq!(m.remove(i), t.id);
                        cx.expect([t.id]);
                    }
                }
                10 => {
                    let mask = arg(input) as u32 | 1;
                    let keep = |id: u32| id.wrapping_mul(mask) & 2 == 0;
                    cx.expect(m.iter().copied().filter(|&id| !keep(id)));
                    m.retain(|&id| keep(id));
                    v.retain(|t| keep(t.id));
                }
                11 => {
                    if depth < MAX_DEPTH {
                        let (elems, mut up) = v.split_above();
                        level(&mut up, input, depth + 1, cx);
                        assert_eq!(ids(elems), m, "a lower vector changed while frozen");
                    }
                }
                12 => break,
                13 => {
                    freeze = true;
                    break;
                }
                14 => {
                    let n = arg(input);
                    v.reserve(n);
                    assert!(v.capacity() >= m.len() + n);
                }
                _ => v.shrink_to_fit(),
            }
            assert_eq!(ids(&v), m);
        }
        if !freeze {
            cx.expect(m.iter().rev().copied());
            drop(v);
            break;
        }
        let s = v.freeze();
        frozen.push((s, m));
        let t = cx.make();
        let id = t.id;
        boxes.push((frame.alloc(t), id));
        for (s, m) in &frozen {
            assert_eq!(ids(s), *m, "a frozen slice changed");
        }
        for (b, id) in &boxes {
            assert_eq!(b.id, *id, "a frozen box changed");
        }
    }
    for (b, id) in boxes {
        cx.expect([id]);
        drop(b);
    }
    for (s, m) in frozen {
        cx.expect(m.iter().rev().copied());
        drop(s);
    }
}

/// Runs one script. Panics on any disagreement with the model.
pub fn run(bytes: &[u8]) {
    let cx = Cx::new();
    {
        let mut st = Stack::with_reserve(1 << 22);
        let mut frame = st.frame();
        let mut input = bytes.iter().copied();
        level(&mut frame, &mut input, 0, &cx);
    }
    cx.finish();
}

```markdown
# Soundness of ordstack

This is an argument, not a mechanised proof. It states the invariants the
`unsafe` code relies on, argues that every public function preserves them,
and lists the hazards considered. The evidence beside it is in
`scripts/check.sh`: compile-fail tests, Miri under both borrow models,
AddressSanitizer, a shadow-model property test and a fuzz target.

## Definitions

- A stack has a region `[0, cap)` and an offset `top`.
- A **frame** `F` has an offset `F.end`. It is created by mutably borrowing a
  **parent**: the stack, another frame, or a growable container. Its
  **start** is the parent's end at that moment.
- A **growable container** `V` holds `&'v mut Frame<'f>`. Its **end** is its
  buffer's capacity end, or the frame's `end` while it has no buffer.
- A **frozen block** is the memory behind an `SBox`, `SSlice`, `SStr` or
  `SFixedVec`. It carries the brand `'f` of the frame that allocated it.
- An object's **end** is `0` for the stack, `F.end` for a frame, and as
  above for a container.

## Invariants

**I (reachability).** Every pointer into the region above an object's end
carries a lifetime that keeps that object mutably borrowed.

**T (top).** For every object that is not currently mutably borrowed by a
live child, `top >=` the object's end.

**E (end is monotone).** `F.end` never decreases, and every frozen block
branded by `F` lies in `[F.start, F.end)`.

**B (buffer).** A container's buffer lies in `[frame.end, V.end)` and holds
`len` initialised values at its start.

## Why I holds

The only ways to obtain a pointer above an object's end are:

| Source | Lifetime on the result | What it borrows |
|---|---|---|
| `Stack::frame(&'a mut self)` | `Frame<'a>` | the stack, for `'a` |
| `Frame::sub(&'a mut self)` | `Frame<'a>` | the frame, for `'a` |
| `SVec::above(&'a mut self)`, `split_above` | `Frame<'a>` | the vector, for `'a` |
| `Frame<'a>::alloc*`, `SFixedVec::with_capacity_in` | handle branded `'a` | nothing new: `'a` already borrows the parent |
| `SVec<'v, 'a, T>::freeze` | `SSlice<'a, T>` | nothing new |
| `SBox::leak`, `SSlice::leak`, `SStr::leak` | `&'a mut` | nothing new |

Every handle type mentions its brand in a covariant position, so a brand can
only be shortened, and a shortened brand is still outlived by the borrow that
created it. `Frame` is neither `Clone` nor `Copy`. No function returns a
pointer or offset without a brand.

## Why reset on reacquire is sound

`Stack::reset_to(off)` is called only by a method that holds `&mut` to an
object whose end is `off` (or, in `freeze` and `shrink_to_fit`, to a point
inside that object's own spare capacity). Holding `&mut` to the object means
no borrow of it is live. By I, every pointer above `off` needs such a borrow.
So nothing above `off` is reachable, and lowering `top` to `off` invalidates
no reachable memory.

Memory below `off` is unaffected: the reset never lowers `top` below the
caller's own end, and by T every object beneath the caller has its end at or
below the caller's start.

## Why growth is in place

`SVec::try_grow_to` holds `&mut self`, resets `top` to the vector's end, and
then either bumps (no buffer yet) or extends. After the reset the buffer ends
exactly at `top`, so extending it overlaps nothing. `Stack::try_extend`
asserts this in debug builds.

## Why frozen blocks stay valid for their brand

By E a block branded by `F` lies below `F.end`. `top` can be lowered below
`F.end` only by a method holding `&mut` to an object beneath `F`, or by
dropping the stack. Every object beneath `F`, and the stack, is mutably
borrowed for at least `F`'s brand. So the block is neither reclaimed nor
unmapped while the brand is alive. `Frame::alloc*` and `freeze` only raise
`end`; `freeze` of an empty buffer leaves it unchanged.

## Hazards

### H1. `mem::forget` and `ManuallyDrop`

No destructor is relied on for memory safety. No type reclaims memory in
`Drop`; destructors only drop values.

- Forgetting a frame or container ends its borrow. Its space is reclaimed at
  the parent's next `&mut` use, or when the stack is dropped.
- Forgetting a frozen handle leaks its value. The brand's borrow is
  unaffected.
- `ManuallyDrop<SVec<..>>` removes the destructor's use of the vector at
  scope end. This lets a block from `split_above`'s frame be stored in the
  vector's own element (`tests/ui/fail/12_*`), which forces the borrow of
  the vector to last as long as its element type. The vector can then never
  be used again, so it can never reset below the stored block; and the frame
  beneath stays borrowed for as long as the element is reachable. The stored
  block is leaked, not dangling.

### H2. Drop check

`SBox`, `SSlice`, `SFixedVec`, `SVec` and `slice::IntoIter` implement `Drop`
without `#[may_dangle]`. The compiler therefore requires every lifetime in
`T`, and the brand, to be alive when the handle is dropped. A destructor of
`T` that reads a frozen block of the same or a lower frame reads memory that
is still allocated, by the previous section. `tests/ui/fail/10_*` and `11_*`
show the compiler rejecting the stores that would otherwise let a lower
container own a block from a frame above it.

### H3. Unwinding out of user code

User code runs inside the library in: element destructors, `Clone::clone`
(`alloc_slice_clone`), iterators (`extend`, `from_iter_in`), the `retain`
predicate, and the `alloc_with` closure.

| Site | State when user code runs | On panic |
|---|---|---|
| `drop_back_to_front` | the owner's `len` is already lowered | a guard drops the rest; a second panic aborts |
| `alloc_slice_clone` | block reserved, `n` slots initialised | a guard drops the `n` clones; the space stays with the frame |
| `Extend::extend` | vector consistent between pushes | elements pushed so far remain |
| `retain` | `len == 0`; kept prefix and unvisited tail tracked by a guard | the guard closes the gap and restores `len` |
| `alloc_with` | nothing reserved | nothing to undo |

In every case `top` and every `end` are consistent, because user code never
runs between a change to `top` and the matching change to a container's
fields.

### H4. Variance

| Type | `'v` | `'f` | `T` |
|---|---|---|---|
| `Frame<'f>` | – | covariant | – |
| `SBox<'f, T>`, `SSlice<'f, T>`, `SFixedVec<'f, T>`, `IntoIter<'f, T>` | – | covariant | covariant |
| `SStr<'f>` | – | covariant | – |
| `SVec<'v, 'f, T>` | covariant | invariant | covariant |
| `SString<'v, 'f>` | covariant | invariant | – |

Shortening a brand is sound (the block is valid for the longer lifetime).
`SVec` must be invariant in `'f` because it holds `&mut Frame<'f>` and
`freeze` returns that brand; it gets this from the reference. Covariance in
`T` is the same as `Vec<T>`'s and `Box<T>`'s: the handles own their values.

### H5. Swapping frames

`mem::swap` on two `&mut Frame<'x>` is safe: each frame carries its own
stack reference and `end`, so the swapped values are still consistent, and
both were already borrowing their parents for `'x`. Two frames at different
depths of one stack cannot be named at once, because the deeper one borrows
the shallower. A sub-frame cannot be moved into a longer-lived slot, because
its brand is the borrow of its parent.

### H6. Zero-size types and alignment

A block of zero bytes is never bumped: handles use `NonNull::dangling()`,
which is aligned. `SVec` gives a zero-size `T` capacity `usize::MAX` and
never allocates; `len` cannot overflow because `try_reserve` checks
`len + additional`. Alignment above 4096 is refused before any state
changes. The region base is page aligned and pages are at least 4096 bytes,
so rounding an offset up to `align <= 4096` aligns the address.

### H7. Arithmetic

Every size computation that can overflow is checked (`checked_mul`,
`checked_add`) and reported as `CapacityOverflow`. The region is at most
`isize::MAX` bytes, so every block satisfies the size limit of
`slice::from_raw_parts`. Offsets within a live buffer (`cap * size_of::<T>()`)
cannot overflow because the buffer exists.

### H8. Threads

`Stack` contains `Cell` and `NonNull`; every handle contains `NonNull` or a
reference to a `Stack`. None is `Send` or `Sync`, and there is no `unsafe
impl` of either (`tests/ui/fail/13_*`, `14_*`).

### H9. The debug shadow

`debug.rs` is a checker, not part of the argument. It uses a thread-local
table; this is correct because a stack cannot leave its thread (H8).

```rust
//! Stack-allocated containers whose stack discipline is proved by the borrow
//! checker.
//!
//! # The guarantee
//!
//! A [`Stack`] is one contiguous address range with a bump pointer. For every
//! stack, in safe code:
//!
//! 1. only the top block is ever grown, and it grows in place;
//! 2. memory is reclaimed only when no live value can reach it.
//!
//! So the allocator keeps no per-block header, never tests whether a block is
//! on top, never copies a block to grow it, and never strands a block under a
//! live one. Breaking the discipline is a compile error, not a run-time check.
//!
//! This is a typed region arena with a growable top. Frozen blocks are not
//! freed one by one, and the crate makes no speed or memory claim against a
//! general-purpose allocator.
//!
//! # Example
//!
//! ```
//! use ordstack::{SVec, Stack};
//!
//! let mut st = Stack::new();
//! let mut f = st.frame();
//!
//! let mut tokens: SVec<&str> = SVec::new_in(&mut f);
//! tokens.extend("let x = 1".split(' '));       // grows in place: it is the top block
//!
//! {
//!     let mut above = tokens.above();           // `tokens` is frozen from here...
//!     let mut lens: SVec<usize> = SVec::new_in(&mut above);
//!     lens.extend(tokens.iter().map(|t| t.len()));
//!     assert_eq!(&*lens, [3, 1, 1, 1]);
//!     // tokens.push("oops");                   // ...so this would not compile
//! }
//!
//! tokens.push(";");                             // top again; `lens` is reclaimed here
//! assert_eq!(tokens.len(), 5);
//! ```
//!
//! # Freeze and descend
//!
//! New space above an object is obtained only by mutably borrowing it:
//! [`Stack::frame`], [`Frame::sub`], [`SVec::above`], [`SVec::split_above`].
//! While the returned [`Frame`], or anything allocated through it, is alive,
//! the object beneath cannot grow or allocate. Holding `&mut` to a growable
//! container is the proof that it is the top block.
//!
//! ```compile_fail
//! use ordstack::{SVec, Stack};
//! let mut st = Stack::new();
//! let mut f = st.frame();
//! let mut lower: SVec<u32> = SVec::new_in(&mut f);
//! let mut above = lower.above();
//! let mut upper: SVec<u32> = SVec::new_in(&mut above);
//! lower.push(1); // error: `lower` is mutably borrowed by `above`
//! upper.push(2);
//! ```
//!
//! # Frozen blocks
//!
//! [`Frame::alloc`] and friends return [`SBox`], [`SSlice`] and [`SStr`]:
//! owning handles to blocks that never move or grow. They are branded with
//! the frame's lifetime, so several can sit side by side and outlive the
//! `&mut` borrow that allocated them. [`SVec::freeze`] turns a growable
//! vector into a frozen slice without copying.
//!
//! ```
//! use ordstack::{SString, Stack};
//!
//! let mut st = Stack::new();
//! let mut f = st.frame();
//! let mut s = SString::new_in(&mut f);
//! s.push_str("hello");
//! let hello = s.freeze();            // the frame is free again
//! let n = f.alloc(hello.len());      // sits beside `hello`
//! assert_eq!((hello.as_str(), *n), ("hello", 5));
//! ```
//!
//! # Reclamation is lazy
//!
//! Nothing is reclaimed when a handle is dropped; destructors only drop
//! values. Space above an object is reclaimed the next time that object is
//! used through `&mut`. To reclaim sooner call [`Frame::reset_above`] or
//! [`Stack::reset`]; to also return pages to the operating system call
//! [`Frame::trim_above`] or [`Stack::trim`]. Leaking a handle is safe.
//!
//! # Patterns
//!
//! **Several stacks.** Two containers that grow in alternation need two
//! stacks. A common split is one stack for results and one for scratch:
//!
//! ```
//! use ordstack::{Frame, SSlice, SVec, Stack};
//!
//! /// Squares of the even numbers, built on `scratch`, returned on `out`.
//! fn even_squares<'o>(xs: &[u32], out: &mut Frame<'o>, scratch: &mut Frame<'_>) -> SSlice<'o, u32> {
//!     let mut tmp: SVec<u32> = SVec::new_in(scratch);
//!     tmp.extend(xs.iter().filter(|x| *x % 2 == 0).map(|x| x * x));
//!     tmp.freeze_into(out)           // one copy; the scratch space is reclaimed later
//! }
//!
//! let (mut a, mut b) = (Stack::new(), Stack::new());
//! let (mut out, mut scratch) = (a.frame(), b.frame());
//! let r = even_squares(&[1, 2, 3, 4], &mut out, &mut scratch);
//! assert_eq!(&*r, [4, 16]);
//! ```
//!
//! **Children on the same stack.** A growable container holds its frame, so
//! its elements cannot allocate from it. When the number of children is known
//! first, use [`SFixedVec`], which does not hold the frame.
//!
//! # Limits
//!
//! - A struct cannot hold a growable container together with the frame it
//!   grows on.
//! - Lifetime parameters spread through signatures.
//! - Frozen blocks are not freed individually.
//! - Nothing here is `Send` or `Sync`.
//! - Unix only in this release; alignment above 4096 is not supported.
//!
//! # Soundness
//!
//! Safety rests on one invariant: every pointer into the region above an
//! object carries a lifetime that keeps that object mutably borrowed. The
//! argument and the list of hazards considered are in `SOUNDNESS.md` in the
//! repository. It is argued and tested, not mechanically proved.
```

## What it is and is not

`ordstack` is a typed region arena with a growable top. Frozen blocks are
reclaimed in bulk, not one by one. It is not an `Allocator` for `std`
collections, not a global allocator, and not thread-safe. It makes no speed
or memory claim against general-purpose allocators.

## How it differs from other bump allocators

| | Growing a container that is not on top |
|---|---|
| `ordstack` | does not compile |
| `bump-scope`, `bumpalo` | allowed; the buffer is copied to a new block and the old one is wasted, or the call fails at run time when the allocator is claimed |
| `dyn-stack` | not applicable: arrays have a fixed size |

Those crates are more flexible and far more mature. Use `ordstack` when you
want the discipline checked at compile time.

[SOUNDNESS.md](SOUNDNESS.md) and tested with Miri, AddressSanitizer, a
shadow-model property test, a fuzz target and compile-fail tests; it is not
mechanically proved. Expect breaking changes before 1.0.

Minimum Rust version: 1.85.

MIT or Apache-2.0, at your option.
