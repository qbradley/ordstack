## Review Focus

1. A `Display` impl that panics in the middle of `sformat!` — expected: the partial string is dropped, the frame stays usable, and the next allocation reuses the space. (Test in Task 2.)
2. A by-value `SVec` iterator that is `mem::forget`-ten — expected: no undefined behaviour (Miri-clean); the remaining elements leak; the frame is usable again and reclaims the buffer. (Test in Task 3.)

5. `Frame::stack()` on a sub-frame or a vector's `above()` frame — expected: statistics of the whole stack, not of the frame. (Test in Task 1.)

    /// The stack this frame allocates from, for reading its statistics
    /// ([`Stack::extent`], [`Stack::high_water`], [`Stack::capacity`]) while
    /// frames and blocks are alive. They describe the whole stack, not this
    /// frame.
    ///
    /// # Examples
    /// ```
    /// use ordstack::Stack;
    ///
    /// let mut st = Stack::with_reserve(1 << 16);
    /// let mut f = st.frame();
    /// let _a = f.alloc([0u8; 100]);
    /// assert_eq!(f.stack().extent(), 100);
    /// ```
    pub fn stack(&self) -> &Stack {
        self.st
    }

    /// Collects `iter` into a frozen block. The elements are collected in
    /// place on top of the stack and frozen without a copy, so the length
    /// need not be known in advance.
    ///
    /// The iterator cannot allocate from this frame, which is borrowed while
    /// it runs.
    ///
    /// # Panics
    /// If the stack is exhausted, the capacity overflows, or a non-zero-size
    /// `T` has alignment above 4096. The elements collected so far are
    /// dropped.
    ///
    /// # Examples
    /// ```
    /// use ordstack::Stack;
    ///
    /// let mut st = Stack::with_reserve(1 << 16);
    /// let mut f = st.frame();
    /// let s = f.alloc_slice_from_iter((1..=3u32).map(|x| x * x));
    /// assert_eq!(&*s, [1, 4, 9]);
    /// ```
    pub fn alloc_slice_from_iter<T, I: IntoIterator<Item = T>>(&mut self, iter: I) -> SSlice<'f, T> {
        SVec::from_iter_in(iter, self).freeze()
    }
```

/// Formats into a frozen string on a frame, like `format!` on the heap.
///
/// The first argument is a `&mut Frame<'f>`; the rest are `format!`'s. The
/// result is an [`SStr<'f>`](crate::SStr). The string is built in place on
/// top of the stack and frozen without a copy.
///
/// # Panics
/// If the stack is exhausted, or if a formatting trait implementation
/// returns an error (as `format!` does). A string that was partly written
/// when a panic occurred is left to be reclaimed.
///
/// # Examples
/// ```
/// use ordstack::{Stack, sformat};
///
/// let mut st = Stack::with_reserve(1 << 16);
/// let mut f = st.frame();
/// let name = sformat!(&mut f, "{}_{}", "node", 7);
/// assert_eq!(name.as_str(), "node_7");
/// ```
#[macro_export]
macro_rules! sformat {
    ($frame:expr, $($arg:tt)*) => {{
        let mut s = $crate::SString::new_in($frame);
        ::core::fmt::Write::write_fmt(&mut s, ::core::format_args!($($arg)*))
            .expect("ordstack: a formatting trait implementation returned an error");
        s.freeze()
    }};
}
```

```rust
/// By-value iterator over an [`SVec`]. It keeps the vector's frame
/// borrowed, so the buffer is not frozen: once the iterator is gone, its
/// space is reclaimed lazily, as for a dropped vector. Elements not yet
/// yielded are dropped back to front.
pub struct VecIntoIter<'v, 'f, T> {
    // Declared first, so it is dropped before the frame borrow ends.
    inner: IntoIter<'v, T>,
    _frame: &'v mut Frame<'f>,
}

impl<'v, 'f, T> IntoIterator for SVec<'v, 'f, T> {
    type Item = T;
    type IntoIter = VecIntoIter<'v, 'f, T>;
    fn into_iter(self) -> VecIntoIter<'v, 'f, T> {
        self.check();
        let (frame, ptr, len, _) = self.into_parts();
        // SAFETY: `ptr` holds `len` initialised values in the vector's buffer,
        // which lies at or above `frame.end`. Only a reset by this frame or by
        // an object beneath it could reclaim the buffer, and the iterator holds
        // `frame` exclusively for `'v`, so neither can run while `inner`
        // exists. With nothing allocated, or for a zero-size `T`, `ptr` is
        // dangling and aligned and the block has zero size.
        let slice = unsafe { SSlice::<'v, T>::from_raw_parts(ptr, len) };
        VecIntoIter {
            inner: slice.into_iter(),
            _frame: frame,
        }
    }
}

impl<T> Iterator for VecIntoIter<'_, '_, T> {
    type Item = T;
    fn next(&mut self) -> Option<T> {
        self.inner.next()
    }
    fn size_hint(&self) -> (usize, Option<usize>) {
        self.inner.size_hint()
    }
}

impl<T> DoubleEndedIterator for VecIntoIter<'_, '_, T> {
    fn next_back(&mut self) -> Option<T> {
        self.inner.next_back()
    }
}

impl<T> ExactSizeIterator for VecIntoIter<'_, '_, T> {}
```

//! something else can reuse one stack for each phase. Consuming a vector by
//! value keeps its frame borrowed, so its buffer is reclaimed afterwards;
//! blocks that were frozen stay until their frame's parent is reused, and
//! [`Stack::reset`] reclaims everything at once ([`Stack::trim`] also
//! returns the pages to the operating system).
//!
//! ```
//! use ordstack::{SVec, Stack};
//!

//!     parsed.extend(0..1000);
//!     parsed.into_iter().sum() // the buffer is reclaimable from here
//! };
//! assert!(st.high_water() >= 8000);
//! st.reset(); // next phase starts from an empty stack
//! let mut f = st.frame();
//! let out = f.alloc(total);
